# ADR-001: 웹 프레임워크로 FastAPI를 선택

- 상태: 승인

## 맥락

Customer Manager 백엔드에는 다음 요구사항이 있다.

- 비동기 처리를 지원해야 한다.
- OpenAPI 기반 API 문서를 자동으로 제공해야 한다.
- 타입 힌트를 활용해야 한다.
- 팀의 주 개발 언어는 Python이다.

## 결정

웹 프레임워크로 **FastAPI**를 선택한다.

검토한 대안은 다음과 같다.

- **Flask**: 유연하지만 API 검증과 문서화를 위한 설정 및 코드가 더 필요하고, 문서 작성도 상당 부분 수작업으로 해야 한다.
- **Django**: 기능이 풍부하지만 현재 서비스의 API 중심 범위에는 과하다.

## 결과

- 적은 코드로 요청 데이터 검증과 API 문서화를 구현할 수 있다.
- 타입 힌트를 바탕으로 OpenAPI 문서를 자동 생성할 수 있다.
- 팀은 FastAPI의 러닝커브를 감수한다.
